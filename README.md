# Pronostici Calcio 1.0

Prima versione Android dimostrativa.

## Funzioni presenti
- Schermata Oggi / Domani
- Partite demo
- Percentuali 1 / X / 2
- Goal / No Goal (prima base: percentuale Goal)
- Over 2.5
- Pronostico consigliato
- Livello di affidabilità
- Pulsante dettagli analisi
- Workflow GitHub Actions per generare APK debug

## Prossimo passo
Collegare una API calcio per ottenere partite, quote statistiche, classifiche e risultati reali.

## APK
Dopo il push su GitHub, aprire **Actions > Build Android APK** e scaricare l'artifact `PronosticiCalcio-v1.0-debug`.
